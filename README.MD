# OpenVLA on LIBERO using LoRA

## The Idea: 
Implementation to adapt an open-source 7B generalist VLA policy to new task distributions using parameter-efficient fine-tuning (PEFT/LoRA) inside a simulator.

## Tools:

1) Model: openvla/openvla-7b (built on LLaMA-2 and Prismatic VLM)
2) Simulation: LIBERO 
3) Framework: Pytorch, HF, peft, and transformers
